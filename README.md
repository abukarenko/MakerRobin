# MKS Robin Nano V3.1 — CoreXY / Marlin 2.1.2.8

Проект для STM32F407VET6 (512 КиБ Flash), TMC2209 UART, ILI9488 SPI и BLTouch.

## Текущий результат

- Прошивка собрана и записана через ST-Link; загрузчик сохранён.
- Пользователь подтвердил нормальные цвета, ориентацию и работу дисплея после калибровки touch.
- XPT2046 работает через программный SPI mode 0 на общей с дисплеем шине. Аппаратный вариант возвращал 4095 по всем каналам.
- Пользователь подтвердил работу BLTouch. Срабатывание через M119, homing и G29 отдельно не зафиксированы.
- Пользователь подтвердил, что вопрос направления X связан с CoreXY; изменения направления не потребовались.
- SpreadCycle отключён по результатам испытаний; используется StealthChop.

## Сборка и запись

```powershell
& "$env:USERPROFILE\.platformio\penv\Scripts\platformio.exe" run -d Marlin-RobinNano31 -e mks_robin_nano_v3_1
.\flash_stlink.cmd
```

Загрузчик пишет `release/Robin_nano_v3.bin` по адресу **0x0800C000**, SWD **1800 кГц**, затем проверяет запись и запускает контроллер. Он не копирует результат новой сборки автоматически: перед записью обновите файл в release из `.pio/build/mks_robin_nano_v3_1/`.

COM21, 115200 бод, 8N1, без управления потоком.

## Подключение

Полная таблица дисплея (номер VDD=1), конфигурация и история изменений: [BUILD_NOTES.md](BUILD_NOTES.md).

BLTouch: управление PA8, питание 5V/GND; сигнал срабатывания PC8 и GND разъёма Z−. TB — термистор стола PC0.
FAN0 PC14 — обдув детали (`M106`/`M107`); FAN1 PB1 — автоматический обдув радиатора хотэнда при 50 °C.

`M995` — калибровка touch; `M995 D` — сырые X/Y/Z1/Z2. После калибровки используйте `M500` для сохранения.

## Содержимое

- `Marlin-RobinNano31/` — исходники и настройки.
- `release/` — текущий BIN, контрольная сумма и архив предыдущих вариантов.
- `firmware_MKS_Robin_Nano V3.1_0x80000.bin` — полный заводской дамп 512 КиБ; не записывать как приложение по адресу 0x0800C000.
- `source_manifest.json`, `configuration_changes.patch` — контроль исходного проекта и изменений.
- `COM21_*.json` — сохранённые результаты диагностики стенда.
